## Reintegration Rule

Every backend change that may need to be moved back into the original backend must be listed here.

Private runtime config files under `backend_copy/app/config/`, including `db.config.js` and `mongodb.config.js`, are local setup requirements only. No committed backend code change was made for these files, and they should not be reintegrated or committed.

When reintegrating:

1. Review this file.
2. Compare the copied backend against the original backend.
3. Move only the required POC-related backend changes.
4. Avoid carrying over unrelated formatting, dependency, or config changes.
5. Test the backend after reintegration.
